# HealthOS foundations release

- **Release:** `healthos-foundations-v1.0.0`
- **Release date:** 2026-09-04
- **Language:** English
- **Status:** frozen foundation

This release contains an original, source-linked orientation to personal health reasoning. It is deliberately neutral about clinicians, commercial programs, and branded optimization systems. It does not reproduce paid courses, transcripts, private records, or proprietary target ranges.

## Files in this release

- [`FOUNDATIONS.md`](FOUNDATIONS.md): course map and eleven compact lessons.
- [`CHEATSHEETS.md`](CHEATSHEETS.md): quick-reference views for labs and screening, exercise, and nutrition.
- [`SOURCES.md`](SOURCES.md): evidence policy and public starting sources.

## Release contract

Treat these three corpus files and this release note as immutable together. Local annotations belong in a separate learner note or overlay. Corrections or content changes create a newly named release with a change note; a preferred framework creates an overlay or fork.

“Frozen” does not mean medically current forever. Before a personal decision, retrieve current local clinical guidance and record the source date and jurisdiction. This course teaches a durable reasoning model; it is not a static screening schedule or treatment protocol.

## Completion

Opening or reading this release does not complete it. Record presentation, acknowledgement, practice, assessment, and mastery separately under the learner-state rules in [`../TEACHING_AND_CUSTOMIZATION.md`](../TEACHING_AND_CUSTOMIZATION.md).

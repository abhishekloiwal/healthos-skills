# Optional deeper teaching

- **Release:** `healthos-depth-v1.1.0`
- **Release date:** 2026-09-06
- **Skill pack:** `1.1.0`
- **Foundation:** `healthos-foundations-v1.0.0`, unchanged

These units extend the [foundation course](../corpus/FOUNDATIONS.md) when a question or learning goal needs more depth. The twelve foundation lessons remain the default sequence. Optional units do not enlarge its completion requirement or change its cursor.

The [HealthOS preventive stance](../corpus/PREVENTIVE_LENSES.md) still guides emphasis: preserve long-term function, address important preventable risks early, and connect measurements to useful decisions. These chapters make that approach more specific. They do not create a second mandatory course or a universal set of laboratory targets.

## Teach and return

1. Read available learner state before choosing the next lesson. Preserve the foundation cursor.
2. Select the smallest unit that answers the question. If the user asked a direct question, answer it without forcing a lesson or assessment.
3. When teaching, explain the unit's concept and source context, then ask its check. Keep the expected answer for assessment; do not display it before the learner attempts the check unless requested.
4. Record the stable unit ID and this depth release, what was presented, and what the response demonstrated. Follow the [learner-state rules](../TEACHING_AND_CUSTOMIZATION.md); one successful check is evidence of understanding, not automatic mastery.
5. Offer another relevant unit or return to the prior foundation position. A teaching exercise becomes an adopted health action only through a separate decision.

## Coverage and evidence

The [source registry](SOURCES.md) and each unit's source basis identify the selected discussions or documents. The teaching is self-contained and distilled; original exercises and cross-source connections are identified where used. Repeated claims were consolidated by learning objective. A rebroadcast, summary or second file is not independent evidence.

The selection favors additional explanation: measurement disagreement, mechanisms, study interpretation and questions that improve decisions. Repeated foundation advice, raw documents, complete transcripts, copied tables, rigid program schedules and speculative treatment protocols are not extra lessons.

Coverage is selective. For example, creatinine interpretation appears in measurements and nutrition, but this release has no kidney-disease curriculum. Hormone, cancer and pain units explain selected concepts; they are not comprehensive diagnostic or treatment courses. For a gap, state that the answer goes beyond the bundled curriculum and use current authoritative sources as described in [answers and actions](../ANSWERS_AND_ACTIONS.md).

Treat the topic files, this index and the source registry as one versioned release. Keep the objective IDs stable in later releases; never reuse one for a different concept. Use [supplements and updates](../SUPPLEMENTS_AND_UPDATES.md) when new material arrives.

# Supplements and source updates

Use this workflow when a new podcast, paper, document or distilled collection arrives. The foundation stays the default course unless the user chooses otherwise. The [optional depth index](depth/INDEX.md) supplies additional teaching, not a second compulsory sequence.

## Decide what the material adds

Keep a compact source note with its identity, original content date, publication or rebroadcast date when different, source locator, audience and relevant topics. Treat an original recording and its transcript, summary and rebroadcast as one source lineage. A collection's download date does not make its claims new.

Read enough of the source and its caveats to assess the actual contribution. Check important claims against the underlying supplied text when a summary is ambiguous. Distinguish the speaker's explanation, a study result, a clinical practice preference and the editor's teaching inference. Do not import a whole archive merely because it is available.

Map each useful contribution to an existing objective or a proposed new one:

| Contribution | Editorial response |
| --- | --- |
| Repeats a known point | Add a useful source reference if warranted; no new lesson. |
| Explains an existing point better | Improve or extend its explanation in a new named release; retain the objective ID. |
| Adds a distinct useful concept | Create a bounded optional unit with prerequisites, source basis and a check. |
| Qualifies or contradicts a taught claim | Compare contexts; record a correction or an explicit unresolved disagreement. |
| Interesting but weak, incomplete or outside the intended teaching scope | Keep as reference-only, or record reviewed with no curriculum change. |

Several episodes may support one unit. One episode may contribute to several distinct units. Neither episode count nor the size of a source folder is a learning objective.

## Distill for teaching

A teaching-ready unit needs a precise purpose, a substantive explanation, source locators, relevant limitations and a short interpretation or application check with an expected-answer basis. Preserve the preventive orientation and the source's actual position. Do not replace distinctive reasoning with generic wellness advice, unsupported medical detail, or a string of warnings.

Consolidate repetition without averaging incompatible recommendations. Keep population, training status, condition, dose context, formulation, measurement method, comparator, outcome and time horizon attached when they matter. A clinician's preferred target is not automatically a universal treatment threshold; a biomarker improvement is not automatically a demonstrated clinical benefit.

Create fresh examples or calculations only when they clarify the sourced concept. Label their assumptions and do not present invented numbers as clinical data. Retain source identity and original dates without requiring users to open private files to understand the shipped lesson.

Use four simple dispositions: **pending review**, **teaching-ready**, **reference-only**, or **reviewed with no curriculum change**. Source preservation alone is not permission for the teacher to present its claims as established. A new reference-only source need not produce a lesson, a new completion requirement or a learner notification.

## Resolve differences explicitly

First ask whether two claims address the same question. A beginner's program and an elite athlete's workload, a concentration and a flow measurement, or a current prevalence and a future incidence risk may differ without contradicting one another. Explain the distinction rather than blending the numbers.

For a real disagreement, retain both positions and compare their supporting methods, populations, outcomes, dates and uncertainties. If the source does not resolve it, teach that limit. If a numerical or factual error is clear, correct the teaching in a new release and record the rationale. Current authoritative clinical guidance still controls personal medical decisions; a frozen source's historical trial status must not be presented as current.

## Release and learner updates

Keep a short change note listing added or revised objective IDs, the reason, source changes and any correction that affects prior teaching. Additive depth can receive a minor skill-pack version while the unchanged foundation retains its own release ID. Preserve old releases in version history; never relabel new content as the old release or renumber objectives merely to insert a lesson.

Append a **pending learner update** only when a change materially affects a proposition, decision framework or uncertainty the person already covered. A duplicate reference or an optional new topic does not invalidate prior learning. Record **update reviewed** only after discussing the change. Preserve previous completion evidence and the main course cursor; a deeper detour has its own scope and progress.

For an out-of-curriculum question, state the gap briefly and proceed with a clearly labelled answer from current authoritative sources when available. Do not claim the curriculum contains that answer, call an unverified source current, or silently add the answer to the released corpus. Later incorporation goes through the same small review process.
